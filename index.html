Sobre mí

Soy Tomas Medel, desarrollador especializado en software seguro con Java, apasionado por crear soluciones robustas y confiables. Mi perseverancia, autodisciplina y capacidad para adaptarme rápidamente a nuevas tecnologías me permiten entregar productos de alta calidad que cumplen con los estándares más exigentes de seguridad.

He desarrollado proyectos diversos, desde sitios web institucionales para parroquias hasta sistemas de monitoreo en tiempo real, además de mantener un portfolio actualizado y contribuciones constantes en GitHub.

Mi perfil combina creatividad y enfoque riguroso, ideal para startups dinámicas y entornos bancarios donde la seguridad y la innovación son clave. Busco oportunidades remotas en equipos proactivos, colaborativos y comunicativos donde pueda seguir creciendo y aportando valor real.

Además, cuento con certificaciones en desarrollo full stack y ciberseguridad que respaldan mi compromiso con las mejores prácticas y el aprendizaje continuo.

Proyectos Destacados

Gestor de Préstamos

Desarrollé una aplicación web completa para la gestión de Recursos Humanos. El sistema permite registrar empleados, gestión de los mismos.

Cuenta con autenticación segura, diseño responsivo, navegación intuitiva y una base de datos estructurada en MySQL. Todo el backend fue construido con Java y Spring Boot, mientras que el frontend utiliza React para ofrecer una experiencia fluida y moderna.

Un proyecto que refleja buenas prácticas de desarrollo seguro, con foco en la eficiencia y la usabilidad.

Curso Universitario Online

Plataforma educativa desarrollada con Java, Spring y PostgreSQL para la gestión de cursos, estudiantes y contenidos. El frontend se construyó con HTML, CSS y JavaScript para una experiencia clara y accesible.

Documentador de Base de Datos

Herramienta interna para documentar estructuras de bases de datos, creada con Java, Spring y PostgreSQL, con interfaz en HTML, CSS y JavaScript para consultas y reportes rápidos.

Portfolio Web

Diseñé y desarrollé mi propio sitio web personal para mostrar mis habilidades, experiencia y proyectos de forma clara y atractiva.

Sitio Web Parroquial

Desarrollé un sitio web sencillo, cálido y funcional para una parroquia local. El objetivo fue ofrecer un espacio accesible donde los fieles pudieran encontrar información sobre misas, actividades, sacramentos y contacto.

El diseño está pensado para usuarios de todas las edades, con una navegación clara, estructura simple y adaptable a dispositivos móviles. El sitio facilita el vínculo entre la comunidad y la parroquia, cumpliendo su función social.

Un proyecto que demuestra sensibilidad al usuario final, diseño centrado en la experiencia y responsabilidad social aplicada a la tecnología.
